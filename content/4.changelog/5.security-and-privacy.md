We've strengthened security throughout ResumAI, focusing on authorization, uploads, payments, exports, and AI analysis.

**Highlights:**

- 🔐 Verify project ownership before uploads, analysis requests, exports, and real-time updates
- ✉️ Require verified email addresses for protected product actions
- 📦 Enforce file-size, file-type, and per-upload limits on both the interface and server
- 💳 Prevent duplicate Stripe events from crediting the same token purchase more than once
- 📊 Protect CSV exports from spreadsheet formula injection
- 🧠 Treat resume and vacancy text strictly as untrusted analysis data, improving resistance to prompt-injection attempts
- 🧹 Remove associated stored files when projects or accounts are deleted
- 🔗 Normalize public URLs and improve permanent redirects for legal pages

These safeguards run behind the scenes while keeping the existing analysis workflow unchanged for legitimate users.
