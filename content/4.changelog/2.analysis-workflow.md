ResumAI now supports a complete project-based workflow for reviewing candidates against a specific role.

**What's new:**

- 📁 Create and manage separate hiring projects
- 🎯 Add a job vacancy to use as the shared evaluation context
- 📄 Upload and manage multiple candidate resumes in each project
- 🤖 Generate structured AI reports with compatibility scores, strengths, gaps, red flags, and interview questions
- ⚡ Follow analysis progress through real-time status updates
- 🔄 Restart incomplete or failed analyses
- 🔔 Receive notifications when processing finishes
- 🗑️ Select and remove multiple resume files at once

These updates make it easier to keep every vacancy, candidate, and analysis result organized in one place.
