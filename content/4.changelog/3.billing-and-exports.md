ResumAI now includes flexible token billing and portable reports for sharing analysis results outside the platform.

**What's included:**

- 💳 Purchase token packs securely through Stripe
- 🪙 See your available token balance before starting an analysis
- 📊 Review clear pricing and token-pack options
- 📑 Export project results as a formatted PDF report
- 📈 Download candidate data as a CSV file for spreadsheets and internal workflows

Tokens are consumed according to the work required for each AI analysis, so you can add more credits whenever you need them without committing to a subscription.
