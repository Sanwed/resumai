Profile avatars now use private storage and authenticated delivery instead of publicly accessible file URLs.

**What changed:**

- 🖼️ Upload a custom image from your profile settings
- 🔒 Store uploaded avatars in private Vercel Blob storage
- 🛡️ Retrieve private avatars through the signed-in ResumAI session
- ⏳ See a clear loading state while an avatar is uploaded or refreshed
- 🌐 Continue using an existing provider avatar when no private upload is present

This update improves profile-image privacy without changing how you manage your account.
