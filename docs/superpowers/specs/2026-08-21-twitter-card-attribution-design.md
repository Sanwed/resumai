# Twitter Card Attribution Design

## Goal

Add account attribution to every Twitter Card generated by ResumAI.

## Design

Extend the existing global `seo.meta` configuration in `nuxt.config.ts` with:

- `twitterSite: '@ResumAI'` for the product account.
- `twitterCreator: '@Sanwed'` for the content creator account.

Keeping both values beside the existing `twitterCard` default applies them consistently to every page while preserving page-specific titles, descriptions, and images.

## Scope

No page-level metadata, runtime environment variables, or content schemas will change.

## Verification

Run the project's type checker and linter to confirm that Nuxt accepts both metadata fields and that the configuration remains valid.
